# Customer Support Chatbot using PHP & MySQL

A simple and user-friendly **Customer Support Chatbot** built using **PHP, MySQL, HTML, CSS, and AJAX**.  
This project is designed to provide instant responses to common customer support questions such as order tracking, refund policy, contact details, and delivery timing.

---

## 📌 Features
- 💬 Interactive chat interface
- ⚡ Instant responses using AJAX
- 🗄️ MySQL database integration
- 🎨 Modern chatbot UI design
- 📦 Order status query support
- 💳 Payment and refund FAQs
- 📞 Contact and support timing details
- 🔁 Easy to add more questions and answers

---

## 🛠️ Technologies Used
- **PHP**
- **MySQL**
- **HTML**
- **CSS**
- **JavaScript / AJAX**
- **XAMPP**
